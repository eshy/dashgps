Supported formats. LigoGPS trailers in .ts files — verified against ~1,230 real clips from an ICESKY dashcam — plus LigoGPS blocks in MP4 atoms, Viidure/INNOVV records, and generic NMEA 0183. Formats marked untested were built from a published sample or a public standard and have never seen a file from that camera. If you own one, send a redacted diagnostic and we will make it work.

Basemap tiles are the only thing on this page that talks to a server; leaving that box unticked keeps the region you drove in on this device too. Want it offline? Download this page as a single HTML file — the whole tool, no server, no install, works with no network at all. dashgps is MIT licensed with no runtime dependencies. It does not replace ExifTool, which reads far more formats — the command-line tool can hand unknown files to your own install.
