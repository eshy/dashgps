dashgps

Pull the GPS track out of dashcam video and export it as CSV, GPX or GeoJSON. Drop in a single clip or a whole trip's folder.

v0.1.0 · source and command-line tool on GitHub

…or drag files and folders anywhere onto this box.

Your video never leaves this device. Parsing happens in your browser, and for the common format only the last few kilobytes of each file are read — so a folder of 1 GB clips is done in seconds.

Timestamps come from the camera's own clock and carry no timezone. Setting the offset the camera was set to makes the exported times real UTC.

Supported formats. LigoGPS trailers in .ts files (verified against ~1,230 real clips from an ICESKY dashcam), LigoGPS blocks in MP4 atoms, Viidure/INNOVV text records, and generic NMEA 0183. Formats marked untested were built from a published sample or a public standard and have never seen a file from that camera — if you own one, send us a diagnostic and we will make it work.

dashgps is MIT licensed and has no runtime dependencies. It does not replace ExifTool, which reads far more formats; the command-line tool can hand unknown files to your own ExifTool install. © dashgps contributors.
